294 """
295 autodiff(::ReverseMode, f, Activity, args::Annotation...)
296
297 Auto-differentiate function `f` at arguments `args` using reverse mode.
298
299 Limitations:
300
301 * `f` may only return a `Real` (of a built-in/primitive type) or `nothing`,
302 not an array, struct, `BigFloat`, etc. To handle vector-valued return
303 types, use a mutating `f!` that returns `nothing` and stores it's return
304 value in one of the arguments, which must be wrapped in a
305 [`Duplicated`](@ref).
306
307 `args` may be numbers, arrays, structs of numbers, structs of arrays and so
308 on. Enzyme will only differentiate in respect to arguments that are wrapped
309 in an [`Active`](@ref) (for arguments whose derivative result must be returned
310 rather than mutated in place, such as primitive types and structs thereof)
311 or [`Duplicated`](@ref) (for mutable arguments like arrays, `Ref`s and structs
312 thereof).
313
314 `Activity` is the Activity of the return value, it may be `Const` or `Active`.
315
316 Example:
317
318 ```jldoctest
319 a = 4.2
320 b = [2.2, 3.3]; ∂f_∂b = zero(b)
321 c = 55; d = 9
322
323 f(a, b, c, d) = a * √(b[1]^2 + b[2]^2) + c^2 * d^2
324 ∂f_∂a, _, _, ∂f_∂d = autodiff(Reverse, f, Active, Active(a), Duplicated(b, ∂f_∂b), Const(c), Active(d))[1]
325
326 # output
327
328 (3.966106403010388, nothing, nothing, 54450.0)
329 ```
330
331 here, `autodiff` returns a tuple
332 ``(\\partial f/\\partial a, \\partial f/\\partial d)``,
333 while ``\\partial f/\\partial b`` will be *added to* `∂f_∂b` (but not returned).
334 `c` will be treated as `Const(c)`.
335
336 One can also request the original returned value of the computation.
337
338 Example:
339
340 ```jldoctest
341 Enzyme.autodiff(ReverseWithPrimal, x->x*x, Active(3.0))
342
343 # output
344
345 ((6.0,), 9.0)
346 ```
347
348 !!! note
349
350 Enzyme gradients with respect to integer values are zero.
351 [`Active`](@ref) will automatically convert plain integers to floating
352 point values, but cannot do so for integer values in tuples and structs.
353 """
