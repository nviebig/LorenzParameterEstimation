8 # transitionary feature to deal versions of Julia that rely on a global context
9 #
10 # Julia 1.9 removed the global LLVM context, requiring to pass a context to codegen APIs,
11 # so the GPUCompiler APIs have been adapted to require passing a Context object as well.
12 # however, on older versions of Julia we cannot make codegen emit into that context. we
13 # could use a hack (serialize + deserialize) to move code into the correct context, however
14 # as it turns out some of our optimization passes erroneously rely on the context being
15 # global and unique, resulting in segfaults when we use a local context instead.
16 #
17 # to work around this mess, and still present a reasonably unified API, we introduce the
18 # JuliaContext helper below, which returns a local context on Julia 1.9, and the global
19 # unique context on all other versions. Once we only support Julia 1.9, we'll deprecate
20 # this helper to a regular `Context()` call.
