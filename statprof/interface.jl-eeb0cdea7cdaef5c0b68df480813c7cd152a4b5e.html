3 # the definition of a new GPU compiler is typically split in two:
4 # - a generic compiler that lives in GPUCompiler.jl (e.g., emitting PTX, SPIR-V, etc)
5 # - a more specific version in a package that targets an environment (e.g. CUDA, ROCm, etc)

74 """
75 CompilerConfig(target, params; kernel=true, entry_abi=:specfunc, name=nothing,
76 always_inline=false)
77
78 Construct a `CompilerConfig` that will be used to drive compilation for the given `target`
79 and `params`.
80
81 Several keyword arguments can be used to customize the compilation process:
82
83 - `kernel`: specifies if the function should be compiled as a kernel (the default) or as a
84 plain function. This toggles certain optimizations, rewrites and validations.
85 - `name`: the name that will be used for the entrypoint function. If `nothing` (the
86 default), the name will be generated automatically.
87 - `entry_abi`: can be either `:specfunc` (the default), or `:func`.
88 - `:specfunc` expects the arguments to be passed in registers, simple return values are
89 returned in registers as well, and complex return values are returned on the stack
90 using `sret`, the calling convention is `fastcc`.
91 - The `:func` abi is simpler with a calling convention of the first argument being the
92 function itself (to support closures), the second argument being a pointer to a vector
93 of boxed Julia values and the third argument being the number of values, the return
94 value will also be boxed. The `:func` abi will internally call the `:specfunc` abi, but
95 is generally easier to invoke directly.
96 - `always_inline` specifies if the Julia front-end should inline all functions into one if
97 possible.
98 - `opt_level`: the optimization level to use (default: 2)
99 - `libraries`: link the GPU runtime and `libdevice` libraries (default: true)
100 - `optimize`: optimize the code (default: true)
101 - `cleanup`: run cleanup passes on the code (default: true)
102 - `validate`: enable optional validation of input and outputs (default: true)
103 - `strip`: strip non-functional metadata and debug information (default: false)
104 """

124 function CompilerConfig(target::AbstractCompilerTarget, params::AbstractCompilerParams;
125 kernel=true, name=nothing, entry_abi=:specfunc, toplevel=true,
126 always_inline=false, opt_level=2, optimize=toplevel,
127 libraries=toplevel, cleanup=toplevel, validate=toplevel,
