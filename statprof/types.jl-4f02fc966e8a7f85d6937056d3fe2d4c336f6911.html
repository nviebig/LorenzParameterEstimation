41 """
42 ModuleExprsSigs
43
44 For a particular source file, the corresponding `ModuleExprsSigs` is a mapping
45 `mod=>exprs=>mt_sigs` of the expressions `exprs` found in `mod` and the method table/signature pairs `mt_sigs`
46 that arise from them. Specifically, if `mes` is a `ModuleExprsSigs`, then `mes[mod][ex]`
47 is a list of method table/signature pairs that result from evaluating `ex` in `mod`. It is possible that
48 this returns `nothing`, which can mean either that `ex` does not define any methods
49 or that the method table/signature pairs have not yet been cached.
50
51 The first `mod` key is guaranteed to be the module into which this file was `include`d.
52
53 To create a `ModuleExprsSigs` from a source file, see [`Revise.parse_source`](@ref).
54 """

71 """
72 FileInfo(mexs::ModuleExprsSigs, cachefile="")
73
74 Structure to hold the per-module expressions found when parsing a
75 single file.
76 `mexs` holds the [`Revise.ModuleExprsSigs`](@ref) for the file.
77
78 Optionally, a `FileInfo` can also record the path to a cache file holding the original source code.
79 This is applicable only for precompiled modules and `Base`.
80 (This cache file is distinct from the original source file that might be edited by the
81 developer, and it will always hold the state
82 of the code when the package was precompiled or Julia's `Base` was built.)
83 When a cache is available, `mexs` will be empty until the file gets edited:
84 the original source code gets parsed only when a revision needs to be made.
85
86 Source cache files greatly reduce the overhead of using Revise.
87 """
