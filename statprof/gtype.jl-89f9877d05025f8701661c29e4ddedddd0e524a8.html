204 """
205 find_leaf_type(hnd::Ptr{T}) where T <: GObject
206
207 For a pointer to a `GObject`, look up its type in the `GType` system and return
208 the Julia leaf type that best matches it. For types supported by Gtk4, for
209 example `GtkWindow`, this will be the leaf type `GtkWindowLeaf`. Some types
210 defined in GTK4 and other libraries are not exported. In this case, the nearest
211 parent type supported by the Julia package will be returned. For example,
212 objects in GIO that implement the GFile interface are returned as
213 `GObjectLeaf`.
214 """
215 function find_leaf_type(hnd::Ptr{T}) where T <: GObject
216 gtyp = G_OBJECT_CLASS_TYPE(hnd)
217 typname = g_type_name(gtyp)
218 while !(typname in keys(gtype_wrappers))
219 gtyp = g_type_parent(gtyp)
220 @assert gtyp != 0
221 typname = g_type_name(gtyp)
222 end
223 gtype_wrappers[typname]
224 end
